The pipeline

  1. 01 Upload Dataset Bring in the raw placement records as a CSV or Excel file — or explore the bundled 50k-student cohort. Live →
  2. 02 Analyse Features Every column in the record — its type, role, coverage, and sample values — before any analysis begins. Live →
  3. 03 Descriptive Statistics Mean, median, spread, and range across twenty numeric fields, then split by placement outcome. Live →
  4. 04 Missing Value Analysis Five skill and activity columns have gaps — measured here, then repaired with mean imputation. Live →
  5. 05 Data Visualization Distributions, correlations, and placement splits — the shape of the data, made visible. Live →
  6. 06 Preprocessing Impute with training means, standardise for the linear model, and seal a stratified 80/20 split — before any model sees data. Live →
  7. 07 Model Training Three classifiers trained on one sealed split — inspect any of them, or benchmark any subset and see the best emerge from the data. Live →
  8. 08 Model Evaluation One honest look at the sealed test set — metrics, ROC curves, confusion matrix, and feature importance. Live →
  9. 09 Predict Placement Enter a student's profile, pick a model — or the recommended best — and get a placement call with its calibrated probability. Live →
